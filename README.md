# Ali-Express-Bundle-Fix
This bookmarklet is used to get to an individual ali express product when the link goes to bundle.  
Because sometimes I don't want to buy 3 different product, I just want the one I clicked on(is that to much to ask for???).  

## Usage
Navigate to an item that is part of a bundle:  
![image](https://github.com/user-attachments/assets/107faa21-2fc2-41a3-9e5b-fe767a5000b2)  
Click on the bookmarklet to convert the page from the bundle page to the actual product page:  
### Before
![image](https://github.com/user-attachments/assets/afd46b63-d26c-47e4-86a7-3dc0aeac97ce)

### After
![image](https://github.com/user-attachments/assets/b9dd3fd9-290a-48f0-92d0-cc04a1213316)

To install the bundle fix, just copy the code from [here](https://raw.githubusercontent.com/s1ddly/Ali-Express-Bundle-Fix/refs/heads/main/Bookmarklet.js) into a new bookmark, and pre-pend the code with "javascript:":
